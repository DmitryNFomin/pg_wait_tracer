## Settled between the two design advisers (do not reopen; build on it)
Read all four: scratchpad/a2go/integ/q-design.md, astra-design.md, fable-challenge.md, astra-settle.md. The outcome:
- No wire or BPF change. Generation membership uses the retained pre-enable acknowledgement vector B as a sufficient condition (a record with seq > B on its cpu/dest and the lifetime's cookie is a member); the merge's t >= e test stays; the post-enable vector is never substituted; markers never anchor (baselines_refreshed is false on every current marker path); TEXT is treated as shared unless exclusivity is independently established.
- Three implementation units. U-P: producer delta (src/discovery_admission.h, src/discovery_attempt.c, src/discovery_producer.c, producer tests). U-M: the two merge nits (already running, merge_capture.c and the host tests). U-I: coordinator and wiring (new src/discovery_integration.{h,c}; src/daemon.{h,c}; src/percpu_transport.{h,c}; src/open_snapshot.c; src/backend.c; integration tests and build registration), src/core/merge.c kept out. Support persistence for the no-wait-word route is separate, explicitly scoped work.
- U-P must add at least: a reserved cookie at bind and for journal witnesses; a numeric-observation record with failed_open, and gone_at / holder class / tgid / parent / fork cookie on resolution; a completed-reconciliation time and counter and a usable permanent-reconciliation-failure outcome; the pre-enable acknowledgement vector; accumulator and on_cpu_ts; an attempts-ended flag; address_compared on the fresh route; strict read > enable; a stable retained-binding token for quiet/no-word handles and for REBIND; explicit inventory and installation reporting for bound lifetimes even when no attachment succeeds; fault delivery sufficient to revoke a committed route-c bound even when history reconciliation fails; renaming only the one tag and three enumerators that collide.
- Census: re-read cursor 0 at each completed checkpoint, serialized with handoff consumption and release; no revision machinery.
- Liveness: when usable reconciliation is lost for the rest of the capture, after consuming retained valid evidence, each still-undisposed cookie-less EXIT gets TERMINAL_UNRESOLVED; attempts stop; ADMIT on independently valid final attachment evidence, otherwise ABANDON only for installed, unambiguously bound, never-admitted identities while the startup gap is open; if the fences abandonment needs cannot complete, the capture is reported incomplete or suspended.
- Shutdown: final refresh before the helpers stop, a total shutdown deadline, a final fault and handoff drain after quiescence. Operational errors become checked fault, pending or incomplete outcomes; none is returned to the daemon's poll loop as a fatal error and none is swallowed as success.
- Rows: 7 merge-only disposition schedules (A04, A05, A06, A10, A20, T2, T3), 12 invalid-claim fixtures; the rest must be classified one by one.
Source snapshots: wt-pc (producer 6e6034c7; a fix round is changing discovery_producer.c internals now, no interface change intended), wt-discm (merge 748218d7).
