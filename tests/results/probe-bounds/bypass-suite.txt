=== #327 evidence-gate BYPASS SUITE, 2026-10-11 ===

Showing that these two scripts can go RED proves the true-positive path, and
that was never the broken one. Every case below is a way their DETECTION
could be made unreachable — a false negative — so each is run and each must
REFUSE rather than print something that reads like a clean run.

Scripts under test:
  run_redgreen.sh      the six-site hang / no-hang evidence
  run_atcap_control.sh the control that says the hang is the CAP's fault

Summary of what must happen, and did:

  #  case                                            expect   got
  -- ----------------------------------------------  -------  --------
  1  run_redgreen: parent slot handed the FIXED       exit 1   exit 1
     binary, so there is no hang to see at all
     (the thing being checked is ABSENT, not wrong)
  2  run_redgreen: `timeout` missing from PATH        exit 1   exit 1
     (dependency exits 127)
  3  run_redgreen: fixed binary chmod -x              exit 1   exit 1
     (dependency exits 126)
  A  control: parent sources absent -> cannot build   exit 2   exit 2
  B  control: the cap+1 -> cap edit silently does     exit 2   exit 2
     not apply, so the "control" would be a second
     copy of the cap+1 run and prove nothing
  C  control: a tree that hangs AT cap too (forced    exit 1   exit 1
     by SESSION_HT_SIZE 1024 -> 512), i.e. the
     harness and not the cap is the cause
  D  control: `timeout` missing from PATH             exit 1   exit 1

Before the hardening, case 1, 2 and 3 all exited 0: run_redgreen.sh printed
whatever it saw and returned success, so "ERROR: exit 127" six times was
indistinguishable from a passing run by exit code. That is the defect this
suite exists to prevent.
